# ngchain.org

The official landing page for **ngchain** — the next-generation blockchain.

Built with **Vite + React**. A single-page, self-contained marketing site
(custom cursor, a subtractive canvas hero, scroll reveals, an interactive
formal model, a signature-scheme comparator, and the ecosystem grid).

## Develop

```bash
npm install
npm run dev      # local dev server
npm run build    # production build -> dist/
npm run preview  # preview the build
```

## Deploy

Pushing to `dev` builds the site and deploys it to GitHub Pages
(`.github/workflows/ghpages.yml`), served at https://ngchain.org.
